Architecture

How the systems are built

Three reference architectures I design and deploy for enterprise clients.

Agentic orchestration over systems of record

Business-function agents never touch enterprise systems directly. A context graph assembled from the systems of record gives agents shared state; custom MCP servers and integration adapters mediate every call; governance wraps the whole stack.

Touchless agentic SDLC

Self-improving agent loops pick up work from the backlog; a code graph of the system gives them context; eval gates decide what merges. Engineers review exceptions instead of every change.

Mainframe modernization as an agent pipeline

A supervised pipeline instead of a bet-the-company rewrite: agents build a code graph of the legacy estate, carve out translation units, generate characterization tests before touching code, and nothing merges without passing verification.

Accelerator 02 · Self-Learning Maintenance

Every resolved ticket makes the next one faster.

EXiQO watches every closed PR, distills the resolution pattern, and crystallizes it into a Claude Code skill. The next time a similar ticket lands, an agent routine fires asynchronously — drafting the fix before an engineer has read the ticket. Maintenance throughput compounds. Your team stays lean.

The compounding loop

Ticket → Pattern → Skill → PR → Distill.

  • 01
    Ticket created
    Hook fires the moment a Jira/ADO issue is filed — no human routing needed.
    Hook · PostIssueCreate
  • 02
    Pattern match against memory
    Claude searches the ticket signature against past resolutions for matching shapes.
    Memory · pattern-recall
  • 03
    Skill auto-invoked, fix drafted
    Matching skill fires. Sub-agent drafts the fix in an isolated worktree, runs targeted tests, opens a PR.
    Skill · Sub-agent · async routine
  • 04
    Engineer reviews & merges
    Lean human team focuses on judgment calls. Hooks gate any production-risky change.
    Hook · PreToolUse guard
  • 05
    Resolution distilled into a skill
    Post-merge, EXiQO inspects the PR diff and creates a SKILL.md capturing the pattern.
    Plugin · skill-codification

Built on Claude Code

Five primitives.
One agentic OS for legacy code.

EXiQO doesn't reinvent the runtime — we extend Claude Code with carefully composed skills, sub-agent topologies, hooks, plugins, and memory schemas. The accelerator ships as a single plugin you install once.

The primitives

How EXiQO uses each one.

Skills

Self-contained markdown workflows with YAML frontmatter. Claude auto-selects them based on the task at hand.

SKILL.md · auto-discovered

Sub-agents

Isolated Claude sessions with their own context. We fan out 5+ specialists in parallel during discovery.

isolation · worktree · parallel

Hooks

Deterministic gates around every tool call. Block writes to billing tables. Audit every PR. Fail closed.

PreToolUse · PostToolUse

Plugins

EXiQO ships as one plugin: skills + hooks + commands + MCPs. claude plugin install exiqo.

marketplace-distributable

Memory

Persistent CLAUDE.md hierarchy plus auto-learned project memory. The platform's institutional knowledge — durable.

CLAUDE.md · auto-memory

  • Documentation drifts; SOPs and runbooks decay

  • Bug-fix patterns never captured — every team re-learns

R Systems · EXiQO model Day 1 → 90

  • 9-day onboarding to ownership · cartography agents in parallel

  • Each resolved bug becomes a reusable skill — platform gets cheaper to run
